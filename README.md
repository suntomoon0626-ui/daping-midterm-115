# 大坪實小 115 上期中評量填報

網站入口：https://suntomoon0626-ui.github.io/daping-midterm-115/

考試期間：2026 年 11 月 2 日至 11 月 6 日，使用雙數週课表。

## 教師使用

開啟網站入口，按「進入共用課表」，選老師姓名、年級與自己的授課時段，填評量科目及範圍。資料存於學校 Google 帳號的 Apps Script 共用儲存，重新整理可取得其他老師的最新填寫。

老師選姓名不具備身分驗證；依使用者要求，持有網址即可進入。伺服器依所選姓名再次檢查授課時段。固定活動禁止填寫，包括主題課、弦樂、社團、樂團、家族生態活動、11/5 各年級指定生態課與星期三下午無課。

## 教務使用

共用課表的「教務管理」需輸入管理碼，才能交換同年級兩個授課時段或更正授課老師。管理碼存於學校 Apps Script 專案的指令碼屬性 ADMIN_PASSWORD；不放在 GitHub，不傳回瀏覽器，不儲存在 localStorage。

已填評量的格子必須先撤回才能調課。相同時段多人同時修改會比對版本，拒絕以舊資料覆蓋最新內容。固定活動不可解除鎖定。

## 程式與部署

index.html 是教師入口。preview.html 是獨立操作展示，只儲存在各自瀏覽器；不作正式收件。

apps-script/Code.gs 與 apps-script/Index.html 是學校 Google 帳號的共用版本來源。正式 Apps Script 專案已部署為「執行身分：擁有者；存取：所有人」。網站入口連到既有部署網址。

GitHub Pages 從 main 分支根目錄發布；Apps Script 檔案的 GitHub 更新不會自動更新 Google 部署，修改後必須同步至學校專案並建立新版本。

## 驗證與限制

- 全部 210 個時段已依原 PDF 第 2 頁逐日放大核對。主題課經教務確認保留禁止排考。
- 已檢查授課限制、固定活動、管理碼、衝突處理、調課與寫入中斷復原。
- Google 實際執行已成功讀寫完整共用快照並開放填寫。
- 匿名 HTTP 連線能取得填報頁。內建瀏覽器同時登入多個 Google 帳號時受到 Google 的多帳號限制，正式填寫的完整瀏覽器流程尚未驗證。若顯示無法開啟檔案，請用無痕視窗開啟；教師填報不需登入。
- 目前使用 Apps Script Properties 共用儲存，不是 Google 試算表。頁面可匯出資料備份。儲存使用分塊壓縮快照及原子指標，並有大小上限。

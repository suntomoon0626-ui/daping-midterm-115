# 大坪實小 115 上期中評量表

網址：https://suntomoon0626-ui.github.io/daping-midterm-115/

開啟網址立即看到全校總表，每一天並排一至六年級。選擇老師後，只將该老師能填的格子亮成黃色。一般考試格留白；已填科目與範圍全校可見。原科目與授課老師保留在滑鼠提示內，固定活動合併顯示並鎖定。

需要換時段時，教務使用表格下方的「教務調課」及管理碼確認。課表與填寫資料沿用學校帳號的共用儲存，沒有重設。

## 原始碼

index.html 是直接可用的全校表，不再是介紹頁。Apps Script 的 Code.gs 與 Index.html 位於 apps-script/。GitHub 網頁以匿名 GET 讀取全校資料，使用 text/plain POST 提交明確操作，保留伺服器端授課、固定活動、管理碼與版本衝突檢查。Apps Script 網頁本身也能顯示相同總表。

教務管理碼只存於學校專案指令碼屬性，不包含在 GitHub。老師依需求直接選姓名，不作帳號驗證。

GitHub Pages 從 main 根目錄部署。修改 Apps Script 檔案後，須同步至 Google 並更新既有部署版本；保持同一個共用網址。
